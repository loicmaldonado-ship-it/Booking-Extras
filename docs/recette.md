Pour chaque anomalie : carte, rôle fictif, projet, étapes, attendu, obtenu, capture, version. Aucun véritable destinataire, document personnel ou secret de production en recette. Les transports externes restent bloqués. L’absence d’email réel est attendue dans cette copie.
